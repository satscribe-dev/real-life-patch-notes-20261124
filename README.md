Entry for the [make.fun bounty "Real-Life Patch Notes: The Comedy Changelog"](https://make.fun/bounty/u-0xb3e689-real-life-patch-notes-the-comedy-changelog-c5844c1d): a program that writes the funniest one-line patch note for a bug in real life or human biology (160 characters max) to `/output/entry.txt`.

## Run

```sh
node main.ts
```

Writes one line (93 characters) to `/output/entry.txt`, deterministically — two runs produce byte-identical output.

## The line

> v4.0.0: fixed a bug where walking into a room instantly deleted the reason you went in there.

Chosen from 10 candidates by pairwise comparison against the judge brief (on-subject, genuinely funny, release-note register, specific recognisable bug, no padding).
